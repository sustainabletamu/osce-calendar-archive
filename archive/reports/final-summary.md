# OSCE archive handoff — November 16, 2026

The archive preserves the public Office of Sustainability calendar for August 2025–December 2026 so staff can reuse prior copy, dates, logistics and images after LiveWhale is replaced. All five project phases passed their verification gates.

**Preserved:** 78 original event IDs, 109 dated display occurrences, 24 locally downloaded full-size public images (20,737,236 bytes), original HTML and plain text, source metadata, captions/alt, nullable original timestamps and all returned fields. Two full-range acquisitions cover all 17 months; the final refresh found no changed event rows. No request or image download failed. Source evidence and media were secured before the interface was built.

**Use:** Extract the whole ZIP, double-click `archive/site/index.html`, search **Campus Earth Day** or **Hullabloom**, apply year/month/topic filters, open a card and copy summary/full description. If clipboard access is blocked, select text and press Command+C/Ctrl+C. Select **Save archived image** for local bytes. `exports/events.csv` has one row per occurrence and can be imported into Sheets/Excel. Local image paths are not Drive links. JSON/raw evidence and physical images remain the source of truth.

**Verified:** 19 automated tests, 16 integrity/reconciliation checks, 20 offline Chromium file:// checks, eight independent public detail pages plus two full-text JSON checks, all 24 media hashes/MIME/dimensions, and raw-only reconstruction with networking denied. Clean ZIP extraction verifies file hashes, relative links and image references; its gallery also passes offline browser checks. Each phase report records evidence and corrected failures. External ZIP checksum and final package/browser verification JSON are supplied alongside the ZIP.

**Limits:** This is a verified archive of returned public data, not a proven complete historical database. Empty months 2025-08, 2026-07, 2026-08 and 2026-12 do not prove no events existed. Deleted, hidden, unpublished or inaccessible history and prior revisions remain unknown. December 2026 is still future relative to capture. Forty-nine records lack a separate full-description field; eight lack summary, 31 lack contact, 28 lack structured location/online URL, and eight lack source media. Thirty-one timed occurrences lack an end. Every event has summary or description. Nulls stay null. Full-size public images are not proven original upload/camera bytes. External websites, PDFs and online meetings require internet.

**Maintain:** Keep the entire archive in at least two storage locations. Follow the README to rebuild offline or run `src/fetch_events.py --refresh` while public service exists, then media, normalization, validation and site scripts. Earlier captures remain even if records later disappear. Review coverage, snapshot changes and missing flags before sharing a refreshed package. A new interface can reuse JSON/images without another scrape. No credentials or fabricated content were used.
