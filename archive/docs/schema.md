# Canonical data and provenance

`events.json` is keyed by string `event_id` representing the original public source identifier. Weekly instances with different IDs are not merged by title. `summary_html_original`, `description_html_original`, and `contact_info_html_original` retain original strings or null. Separate `*_text` fields support search/copy; separate `*_html_safe` fields are built through a conservative HTML allowlist. All source attributes, including unnormalized dates and image HTML, survive in `source_fields` and immutable raw response bodies. The latest observed variant is selected for display; variants are not silently discarded. `raw_source_refs` gives response path, source request URL, source ID/date, and UTC acquisition time. `first_seen_at_utc` is acquisition time, not original publication time.

`occurrences.json` has one display date/time slot per original `(event_id,date_iso,date2_iso)` tuple. Its stable `occurrence_id` combines source ID and a 20-hex SHA-256 prefix over that tuple. `end_iso_original` stays null when absent, including all-day entries; display conversion uses America/Chicago. Original UTC, epoch, offsets, source display dates, and repeat bounds remain in `recurrence_source_fields`. Multi-day event rows represent daily display occurrences of a spanning event; they are not automatically independent sessions. Earlier observations persist across refreshes with a visibility flag.

`assets.json` uses the SHA-256 of actual downloaded bytes as identity. It holds image source URL aliases, local path, size, verified MIME/dimensions, capture time, status, quality decision, warnings, raw response references, and per-event `claims` preserving distinct captions/alternative text for shared images. A null caption is not invented. An image download failure is separate from a source event that provides no image. The current 24 assets all downloaded successfully; the two extra physical discovery thumbnails are evidence outside this canonical count.

`real-record-example.json` contains a labelled subset of the actual archived public event 359398 and its occurrence/image references. It is documentation, not a sample inserted into production exports. Full records and complete field lists are in `data/`. CSV exports are occurrence-grain; the gallery is event-grain with all captured occurrence dates visible.

Raw capture metadata contains exact request/final URLs, status, UTC acquisition times, byte count and SHA-256. `raw/manifest.json` selects the latest monthly extraction; `raw/snapshots/*/extraction.json` retains every earlier extraction. Raw bodies are never sanitized or reserialized. Response headers and documentation are retained as evidence; embedded source HTML should always be treated as untrusted if a new interface is built.
